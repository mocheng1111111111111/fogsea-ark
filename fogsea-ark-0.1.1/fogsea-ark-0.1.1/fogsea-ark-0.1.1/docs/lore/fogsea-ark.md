# 雾海方舟

很久以前，世界并不是这样的。

那时天空晴朗，大地辽阔，人们沿着河流建造城市，在海岸点亮灯塔。直到某一天，一场无法解释的大雾从海的尽头涌来。

它吞没了港口、森林与城镇，淹没了道路，也带走了太阳。被雾笼罩的土地逐渐失去生机，而雾中开始出现形态诡异的生物。人们称它们为——雾裔。

幸存者们逃离陆地，登上了最后的方舟。

方舟依靠一枚古老的核心维持运转。它能驱散周围的浓雾，为人们提供一片短暂的安全之地。但核心的力量正在衰退，方舟无法永远漂泊下去。

为了寻找新的家园，方舟在一座荒芜的岛屿附近停泊。

这里有树木、石料，也有能够维持核心运转的雾晶。或许，这里可以成为新的避难所。

但每当太阳落下，雾海便会苏醒。

雾裔从岛屿边缘涌来，试图摧毁核心，夺走最后的光。

于是，守灯人接过了职责。

白昼，收集物资，修建防线，让荒岛逐渐变成堡垒。

黑夜，守住灯火，抵挡一波又一波的雾潮。

传说，每隔七个夜晚，雾海深处便会出现一位古老的存在。它是雾潮的源头，也是所有雾裔的主人。

没有人知道击败它之后会发生什么。

但至少，在那之前——
